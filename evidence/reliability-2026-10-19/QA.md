Основа: `773ba67fdafe46c1cc4ada869636439e1f3d8991`. Работа выполнена в `MOYISEY/rowline` на синтетических CSV. До начала `main` совпадал с `origin/main`, рабочее дерево было чистым. ## Что воспроизведено и исправлено

| Сценарий | Исходная версия | После исправления |
| --- | --- | --- |
| `sku,name` с `A,keep`, `A,drop`, `A,broken,EXTRA`; для `sku` включена точная уникальность | Диалог «Оставить №2» предлагал исключить №3 **и №4**. У №4 неверная структура, она не участвовала в проверке уникальности. | Диалог предлагает исключить только №3. №4 остаётся отклонённой с ошибкой структуры и полным исходным JSON в rejected CSV. |
| Escape после отправки CSV в worker, до ответа разбора или обработки | Окно закрывалось, но ответ позже заменял текущую таблицу, ручные правки и историю. | Отмена делает этот запрос недействительным. Экспорт, opt-in сохранение, undo/redo и выбранная запись остаются от принятой работы. |
| Последовательно выбраны медленный и новый файлы | Первый запрос мог завершиться позже второго и перезаписать выбранный результат; чтение файла не отмечалось занятостью. | Последний выбор побеждает. Отменённое чтение CSV или JSON-копии не устанавливает результат. |
| Восстановление корректной по формату копии, чьи правила дают результат свыше 8 МБ | Копия устанавливалась до ошибки обработки, из-за чего экспорт блокировался; прежняя работа переставала быть доступна. | Разбор и обработка завершаются до замены. При ошибке прежние данные, локальная копия и история доступны. То же правило действует для импортированного рецепта. |
| Браузер запретил удалить opt-in копию после успешной замены | При финальной проверке обнаружен риск скрыть сообщение об отказе сбросом ошибки. | Предупреждение остаётся видимым, текущие данные и экспорт работают. |

Загрузка стала единой завершённой операцией: worker разбирает и обрабатывает вход до установки в UI. Каждое начатое чтение/загрузка получает номер; результат прежней или отменённой операции игнорируется. Подготовленный результат используется один раз, чтобы повторный пересчёт после undo/redo оставался корректным. Проверка членства в группе дубликатов использует фактическую ошибку `unique` той же колонки. CSV-ядро, worker, стили, зависимости, прежние сценарии и образец данных содержательно не менялись; [машинная сверка](checks.json) перечисляет 13 защищённых файлов и хэши assets/кадров.

## Проверки

- На опубликованной основе 29/29 unit/security и 22/22 старых сценария Edge desktop/touch прошли. Из 14 новых отрицательных прогонов 10 завершились несоответствием, 2 истекли по времени из-за блокировки экспорта после ошибки восстановления, 2 проверки CSV round-trip уже проходили. Отказы сохранены отдельно с исходными trace в локальном QA-каталоге.
- На финальной локальной сборке 29/29 unit/security, TypeScript и Vite build прошли; 42/42 старых и новых сценария Edge desktop/touch прошли. Версия установленного Edge: `155.0.4283.62`.
- Исходная Playwright-матрица Chromium/Firefox/WebKit × desktop/mobile: **126/126 прошли** (21 сценарий на каждом из шести профилей, последовательный запуск). Touch здесь означает эмуляцию; Playwright WebKit не заменяет физический Safari.
- Новые сценарии проверяют отмену на стадиях `parse` и `process`, выбор файла при медленном чтении, отказ восстановить ошибочный CSV/копию/рецепт без потери текущей работы, два цикла undo/redo, клавиши Enter/Escape/Ctrl+Z/Ctrl+Shift+Z, защиту и точный экспорт. UI round-trip сохраняет BOM, запятые в кавычках, двойные кавычки, CRLF внутри поля, пустые значения и ведущие нули при всех четырёх разделителях. Сетевых POST/PUT/PATCH тест не увидел.
- В синтетическом тесте 10 000 записей один замер Edge до/после составил desktop `217 → 198` мс и touch `225 → 193` мс для import + worker + render. Это диагностические единичные замеры, а не доказательство ускорения. В сборке основной JS увеличился с 313 289 до 314 336 байт; worker остался побайтно тем же.

Для повтора: `npm run check`; `BASE_URL=http://127.0.0.1:4178 npm run test:e2e -- --workers=1` с запущенным `npm run preview -- --port 4178`; для установленного Edge задать `PLAYWRIGHT_CHANNEL=msedge` и выбрать проекты `chromium-desktop`, `chromium-mobile`. CI использует ту же матрицу без переменной канала.
